# ClearRate — fictional finance comparison site

Static, dependency-free demo of a US finance review/comparison portal. Every brand, rating, rate and product condition is fictional.

## Run locally

Open `index.html` directly in a browser, or run any static server in this folder:

```bash
npx serve .
```

## What is included

- Responsive comparison layout for desktop and mobile
- Six fictional US finance offers
- Filters by product type and user profile
- Sorting by editorial score, APR and annual fee
- Working demo buttons, review states and newsletter form
- Partner disclosure and methodology section
- No external dependencies or API keys

## GitHub Pages

Push the folder to a repository and enable GitHub Pages from the repository's Actions or Pages settings. The entry point is `index.html`.

This is an educational UI example, not financial advice and not a live affiliate site.
